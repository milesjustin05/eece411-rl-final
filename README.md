## Requirements

- **Python 3.13** (required: `simulator.pyc` is compiled for 3.13 and will not load on other versions)

## Setup

1. Clone the repository and move into it:

   ```
   git clone https://github.com/milesjustin05/eece411-rl-final.git
   cd eece411-rl-final
   ```

2. Create and activate a virtual environment:

   **Windows (PowerShell):**
   ```
   py -3.13 -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

   **macOS / Linux:**
   ```
   python3.13 -m venv .venv
   source .venv/bin/activate
   ```

3. Install dependencies:

   ```
   pip install -r requirements.txt
   ```
